# Search for oneWire Address

This searches for a 1-wire device, and then lists the address.

The line needs a  pullup. For the Wio Terminal its the right hand connector - white wire.

It has been tested onDS18B20 and 
Wio_Terminal - with the address displayed on screen and also on th terminal
